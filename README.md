# Python Alıştırmaları

Temel Python programlama konularını pekiştirmek amacıyla geliştirilmiş çeşitli programlama alıştırmaları ve uygulama örnekleri.

## Genel Bakış

Bu repository, Python öğrenme sürecinde temel programlama konularını uygulamak ve farklı problem senaryoları üzerinde pratik yapmak amacıyla oluşturulmuştur.

İçerisinde farklı konulara yönelik küçük Python programları ve uygulama örnekleri bulunmaktadır.

## İçerik

Repository içerisinde aşağıdaki gibi farklı çalışmalar bulunmaktadır:

- Hesap makinesi
- Mükemmel sayı kontrolü
- Sayı tahmin oyunu
- Şirket çalışanları yönetimi
- Tasarıma uygun ev fiyatı hesaplama

Her çalışma, belirli bir programlama problemini çözmek ve Python'un temel yapılarını uygulamak amacıyla geliştirilmiştir.

## Kullanılan Konular

Çalışmalarda temel Python programlama konularından yararlanılmıştır:

- Değişkenler ve veri tipleri
- Koşul ifadeleri
- Döngüler
- Fonksiyonlar
- Kullanıcı girdileri
- Listeler ve diğer temel veri yapıları
- Hesaplama ve problem çözme
- Dosya ve modül yapısı

## Proje Yapısı

```text
PythonAlistirmalari/
├── hesap_makinesi/
├── mukemmel_sayi/
├── sayi_tahmin/
├── sirket_calisanlari/
├── tasarima_uygun_ev_fiyati/
└── README.md
```

Her klasör, farklı bir Python alıştırması veya uygulama örneğini içermektedir.

## Projenin Amacı

Bu repository'nin temel amacı, Python programlama temellerini uygulamalı olarak öğrenmek ve problem çözme becerilerini geliştirmektir.

Çalışmalar, farklı programlama problemlerini küçük ve bağımsız uygulamalar halinde çözerek Python pratiği yapmayı amaçlamaktadır.

## Proje Durumu

Bu repository bir öğrenme ve pratik çalışmasıdır.

Yeni Python konuları öğrenildikçe veya farklı problem senaryoları üzerinde çalışıldıkça yeni alıştırmalar eklenebilir.

## Çalıştırma

Her çalışma bağımsız bir Python programı olarak çalıştırılabilir.

Örneğin:

```bash
python dosya_adi.py
```

Çalıştırılacak dosya, ilgili alıştırmanın klasöründeki Python dosyasına göre belirlenmelidir.
